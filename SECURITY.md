# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of PersianDate.

| Version           | Supported |
| ----------------- | --------- |
| 2.1.x             | Yes       |
| 2.0.x and earlier | No        |

Users are encouraged to upgrade to the latest available release.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

To report a vulnerability, email:

**[milaninia.h@gmail.com](mailto:milaninia.h@gmail.com)**

Please include:

* A clear description of the issue
* The affected version
* Steps or sample code needed to reproduce it
* The potential impact
* Any suggested mitigation, if available

The report will be reviewed as soon as practical. Please allow time for investigation and correction before publicly disclosing the issue.

## Scope

Security reports may include issues such as:

* Memory corruption or unsafe memory access
* Invalid input causing unexpected behavior
* Integer overflow affecting date calculations
* Platform-specific failures that may affect system reliability
* Vulnerabilities introduced through build or release workflows
